# GPL-3.0-only to reuse Read Frog prompts

sidelingo is licensed GPL-3.0-only so it can reuse Read Frog's prompts verbatim instead of inventing its own prompt wording. Read Frog is dual-licensed under GPLv3 (without an "or later" clause) and a commercial license, so a verbatim copy makes sidelingo a derivative work bound to GPL-3.0.

## Considered Options

- **AGPL-3.0**: compatible through GPLv3 section 13, but its network clause adds nothing for a desktop app.
- **A permissive license with rewritten prompts**: keeps licensing freedom, but means authoring prompts ourselves, which is what we set out to avoid.

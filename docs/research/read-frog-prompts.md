# Read Frog prompts for Structuring, Translation, and Lookup

Research for [#3](https://github.com/mcdp-adk/sidelingo/issues/3). It inventories the Read Frog prompts and mechanisms that map onto sidelingo's Structuring, Translation, and Lookup (see `CONTEXT.md`), and notes where the mapping has gaps. It reports facts only and does not design sidelingo's pipeline.

**Source.** [mengxi-ream/read-frog](https://github.com/mengxi-ream/read-frog) at commit [`b4a45b9`](https://github.com/mengxi-ream/read-frog/tree/b4a45b9455eb0f63b450cb9610d87ac33883f0e9) (2026-09-27). All `src/...` links below point at that commit. Dictionary labels come from the npm package [`@read-frog/definitions@0.5.1`](https://unpkg.com/@read-frog/definitions@0.5.1/), which Read Frog pins in `package.json`. That package's source lives in `mengxi-ream/read-frog-monorepo` (`packages/definitions`).

Prompts are summarized here, not copied. Follow the links for the full wording.

## Summary

| sidelingo step | Closest Read Frog counterpart | Status in Read Frog |
|---|---|---|
| Structuring (text) | None. Defuddle turns page HTML into Markdown for context only, with no LLM involved. | Gap |
| Structuring (image) | None. No prompt anywhere sends an image. | Gap |
| Entry vs. running text | None automatic today. The user picks Translate or Dictionary. A removed prompt had the LLM choose. | Gap (legacy prompt exists) |
| Source language detection | `franc` locally; optional LLM prompt | Active |
| Translation | Page-translation prompt family (`default`, `precision-rewrite`) | Active |
| AI context-aware translation | Page summary → `{{webSummary}}` in the translation system prompt | Active, off by default |
| Lookup | Built-in **Dictionary** custom action (structured JSON) | Active |
| Lookup (legacy Markdown card) | `getWordExplainPrompt`, with per-language `LANG_DICTIONARY_LABELS` | Present, no caller |

## 1. Prompt inventory

Template tokens use the `{{name}}` syntax and are replaced with `replaceAll` ([`constants/prompt.ts#L57`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/prompt.ts#L57)). Almost every prompt is split into a system message (`instructions`) and a user message (`prompt`), both plain strings.

### 1.1 Translation (page, selection, input, Translation Hub)

**Builder.** [`getTranslatePromptFromConfig`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/translate.ts#L63-L153) and its async wrapper [`getTranslatePrompt`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/translate.ts#L155-L175). The builder selects a prompt by id: a built-in one, then a user-defined pattern, then `default` as the fallback. It appends optional blocks, replaces tokens, and finally appends the glossary block. It returns `{ systemPrompt, prompt }`.

**Tokens.** `WEB_PAGE_PROMPT_TOKENS` are `targetLanguage`, `input`, `webTitle`, `webDescription`, `webContent`, and `webSummary` ([`constants/prompt.ts#L8-L15`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/prompt.ts#L8-L15)). `targetLanguage` is an English language name taken from `LANG_CODE_TO_EN_NAME`, not a code ([`execute-translate.ts#L77-L85`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/execute-translate.ts#L77-L85)). A missing or blank context value becomes a literal fallback string such as `"No title available"` or `"No summary available"` ([`translate.ts#L115-L127`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/translate.ts#L115-L127)). The translation prompt has **no source-language token**, so the model infers the source language itself.

**Built-in prompts** ([registry `#L132-L143`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/prompt.ts#L132-L143)):

Rules: output only the translation, keep the same paragraph count and format, place HTML tags sensibly, keep untranslatables (proper nouns, code). ### 1.4 Language detection

[`getLanguageDetectionSystemPrompt()`, `language-detection.ts#L34-L72`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/language-detection.ts#L34-L72). The system prompt asks for raw JSON `{ reason, code }` with an ISO 639-3 `code`. It includes one worked example (Classical Chinese → `cmn`), the rule to use `und` for unsupported languages, and the full list of supported codes. The user message is the raw text. Putting `reason` before `code` acts as deliberate "soft reasoning" ([header comment `#L1-L13`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/language-detection.ts#L1-L13)). Section 3.2 covers usage.

### 1.5 Dictionary (the current Lookup mechanism)

The built-in **Dictionary** is a "custom AI action" with the reserved id `default-dictionary` ([`custom-action.ts#L10`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/custom-action.ts#L10)). It is built at read time from the `dictionary` template ([`custom-action-templates.ts#L24-L84`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/custom-action-templates.ts#L24-L84), [`createDefaultDictionaryAction`, `constants/config.ts#L64-L79`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/config.ts#L64-L79)).

- **Prompt text lives in the i18n files** and follows the extension's UI locale. English is at [`en.yml#L759-L823`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/locales/en.yml#L759-L823) and Simplified Chinese at [`zh-CN.yml#L759-L823`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/locales/zh-CN.yml#L759-L823).
  - The system prompt ([`en.yml#L762-L804`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/locales/en.yml#L762-L804)) casts the model as a dictionary assistant for language learners, with 10 rules. It should use the sense that fits the paragraphs and normalize the term to its lemma. The sentence must be the single complete sentence that contains the term, and the sentence translation covers only that sentence. Phonetics use the language's standard notation (IPA, pinyin, romaji). Part of speech is in English, difficulty is a CEFR level, unknown fields are empty strings, and textual fields are in `{{targetLanguage}}`. Two few-shot examples follow: English→Chinese "blossoms" and Japanese→English "感動".
  - The user prompt ([`en.yml#L805-L809`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/locales/en.yml#L805-L809)) is `## Input` followed by `Selection: {{selection}}`, `Paragraphs: {{paragraphs}}`, and `Target language: {{targetLanguage}}`.
- **Output shape.** A JSON object with seven nullable string fields, in this order: Term, Phonetic, Part of Speech, Definition, Sentence, Sentence Translation, Difficulty. Field descriptions are at [`en.yml#L810-L823`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/locales/en.yml#L810-L823). The JSON **keys are the localized field names**, so a zh-CN UI yields keys such as `词条`, `音标`, and `词性`. The Definition is a single target-language definition. There is no separate source-language explanation.
- **Assembly.** [`buildSelectionToolbarCustomActionSystemPrompt`, `custom-action-prompt.ts#L91-L100`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/custom-action-prompt.ts#L91-L100) replaces the tokens in the action's system prompt and appends a generic "Structured Output Contract" ([`#L68-L89`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/custom-action-prompt.ts#L68-L89)). The contract lists each field as a YAML-ish `key/type/nullable/description` entry, followed by 7 hard JSON rules. The tokens are `selection`, `paragraphs`, `targetLanguage`, `webTitle`, `webUrl`, and `webContent` ([`#L4-L27`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/custom-action-prompt.ts#L4-L27)).
- **Generation.** For a local provider, it calls the AI SDK's `streamText` with `Output.object({ schema })` ([`background-stream.ts#L831-L855`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/background-stream.ts#L831-L855)). The schema is a zod `strictObject` of nullable strings or numbers keyed by field name ([`structured-object-schema.ts#L4-L18`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/ai/structured-object-schema.ts#L4-L18)). Partial objects stream to the UI ([`use-custom-action-execution.ts#L377-L440`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/custom-action-button/use-custom-action-execution.ts#L377-L440)).
- **Rendering.** It is a generic field list, not a styled dictionary card ([`structured-object-renderer.tsx#L46-L161`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/custom-action-button/structured-object-renderer.tsx#L46-L161)). Each field is one row: a small muted label (the field name plus a type icon), then the value as pre-wrapped text. A field shows `…` while streaming and `—` when empty. Term and Sentence carry a speak (TTS) button (`speaking: true` in the template). Above the rows, [`custom-action-content.tsx#L14-L39`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/custom-action-button/custom-action-content.tsx#L14-L39) shows the selected source text. An optional "Thinking" block shows reasoning output.

The two other templates are listed for completeness. **Improve Writing** returns Error Analysis and Improved Version, and its prompt asks the model to detect the origin language itself. **Blank** is an empty template ([`custom-action-templates.ts#L85-L131`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/custom-action-templates.ts#L85-L131)).

### 1.6 Word explanation (legacy Markdown dictionary card, no caller)

[`getWordExplainPrompt(sourceLang, targetLang, langLevel)`, `word-explain.ts#L4-L76`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/word-explain.ts#L4-L76) is still in the tree, but nothing imports it. Its caller, the selection toolbar "AI button / Vocabulary Insight", was removed in [`eb150b7` (#1166)](https://github.com/mengxi-ream/read-frog/commit/eb150b751f6c4f42bf73ca60547eb074ea89128f). The changeset says Dictionary custom actions are the supported replacement.

- **Inputs.** Source and target language (ISO 639-3) and the learner level (`beginner`/`intermediate`/`advanced`, mapped to CEFR bands). Before removal, the user message was `query: <selection>\ncontext: <paragraphs>`. The source language was the config value or, when set to `auto`, the page-level detected code. The request used temperature 0.2, and the result was rendered with `MarkdownRenderer`. (Taken from `ai-button.tsx` at `eb150b7^`, lines 137–160 and 292.)
- **Behaviour.** The LLM itself decides whether the query is a word/phrase or a sentence ([`#L23-L26`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/word-explain.ts#L23-L26)), then fills one of two Markdown templates:
  - **Word template** ([`#L42-L64`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/word-explain.ts#L42-L64)): `# word`, bold pronunciation, part of speech, then `## Definition` with a bold **source-language definition**, a target-language definition, and an example sentence in the source language. After that come `## Root`, `## Extended Vocabulary` (synonyms and antonyms), and optional language-specific extras.
  - **Sentence template** ([`#L66-L74`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/prompts/word-explain.ts#L66-L74)): a bold translation, `## Grammar Point`, and `## Explanation` in context.
- **Per-language labels.** `LANG_DICTIONARY_LABELS` from `@read-frog/definitions` ([`dictionary.ts#L7-L19` interface, `#L21` map](https://unpkg.com/@read-frog/definitions@0.5.1/src/constants/dictionary.ts)) holds 179 languages. Each has 11 labels: `pronunciation`, `partOfSpeech`, `definition`, `exampleSentence`, `extendedVocabulary`, `synonyms`, `antonyms`, `root`, `grammarPoint`, `explanation`, and `uniqueAttributes`. Pronunciation names the scheme, for example `eng` → "IPA", `cmn` → "拼音", `jpn` → "平仮名". Headings come from the **target** language's labels, and the pronunciation label from the **source** language's. `uniqueAttributes` is a conditional template block for some languages, such as English phrasal verbs or Japanese verb conjugations; 169 of the 179 entries leave it empty.

## 2. AI context-aware translation (AI 智能上下文翻译)

The feature is labelled "AI smart context translation" / "AI 智能上下文翻译" ([`en.yml#L329-L333`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/locales/en.yml#L329-L333), [`zh-CN.yml#L329-L333`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/locales/zh-CN.yml#L329-L333)). The UI copy says the AI reads a page or video summary before translating, that this applies to every LLM translation feature, and that it adds first-request latency and API cost. It is controlled by `pageTranslation.enableAIContentAware`, which defaults to `false` ([`constants/config.ts#L112`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/config.ts#L112)).

**1. Gather page context (content script, no LLM).** [`getOrCreateWebPageContext`, `webpage-context.ts#L37-L52`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/webpage-context.ts#L37-L52) builds `{ url, webTitle, webDescription, webContent }`. It caches the result in memory per URL.

- `webTitle` is `document.title`.
- `webDescription` is the first non-empty `meta[name=description]`, `og:description`, or `twitter:description` ([`metadata.ts#L5-L20`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/content/metadata.ts#L5-L20)).
- `webContent` is the main content extracted by **Defuddle** from a clone of the DOM, as Markdown. It falls back to `document.body.textContent` and is truncated to **2000 characters** ([`webpage-context.ts#L19-L35`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/webpage-context.ts#L19-L35), [`webpage-content.ts#L1-L5`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/webpage-content.ts#L1-L5)).

**2. Decide whether to summarize.** [`getOrGenerateWebPageSummary`, `webpage-summary.ts#L11-L34`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/webpage-summary.ts#L11-L34) returns `null` in three cases: the toggle is off, the title is empty, or the content is empty. Only LLM providers get context at all. Pure translation APIs (Google, Microsoft, DeepL) receive none ([`translate-variants.ts#L36-L87`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/translate-variants.ts#L36-L87)).

**3. Summarize (background).**

- The message handler is [`page-translation.ts#L176-L201`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/page-translation.ts#L176-L201). It calls [`getOrGenerateTranslationContextSummary`, `translation-context-summary.ts#L18-L82`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/translation-context-summary.ts#L18-L82).
- Before the LLM call, whitespace and zero-width characters are collapsed. The body is capped at 3000 characters (`MAX_TEXT_LENGTH`) and the title at 200 ([`content/summary.ts#L10`, `#L32-L42`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/content/summary.ts#L10-L42), [`content/utils.ts#L1-L16`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/content/utils.ts#L1-L16)). Since the input is already capped at 2000 characters, 2000 is the effective limit.
- The summary prompt is the one in section 1.2, and it runs on the **same provider as the translation**.
- **Cache.** The IndexedDB table `articleSummaryCache` uses the key `Sha256(webTitle, Sha256(cleanText(webContent)), providerCacheIdentity)` ([`page-translation.ts#L198`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/page-translation.ts#L198), [`translation-context-summary.ts#L37-L43`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/translation-context-summary.ts#L37-L43)). The cache is checked again inside the queued task, and requests are de-duplicated through `RequestQueue` by key ([`#L50-L76`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/translation-context-summary.ts#L50-L76)). Entries expire after 7 days ([`db-cleanup.ts#L15-L16`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/db-cleanup.ts#L15-L16)).
- Failure is soft: the summary becomes `null` and translation proceeds without it.
- Subtitles reuse the same function, with the transcript as content and a key based on the transcript alone ([`subtitles-translation.ts#L93-L115`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/subtitles-translation.ts#L93-L115)).

**4. Inject into the translation prompt.** The context object `{ webTitle, webDescription, webContent, webSummary }` travels with each translation request. The builder replaces `{{webTitle}}` and `{{webSummary}}` inside the system prompt's "Document Metadata for Context Awareness" section (section 1.1). `{{webDescription}}` and `{{webContent}}` are replaced as well, but only custom prompts contain them. Title and description are sent to LLM providers **even when the toggle is off**, because `getWebPagePromptContext` always returns them. The toggle only gates the summary. The exception is page-title translation, which omits all context when the toggle is off ([`translate-variants.ts#L192-L210`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/translate-variants.ts#L192-L210)). Selection translation does the same gathering in [`getSelectionWebPagePromptContext`, `provider.tsx#L92-L115`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/translate-button/provider.tsx#L92-L115).

**5. Translation cache.** For page and input translation, the translation cache key hashes the prepared text, provider identity, source and target codes, the full rendered system and user prompts, and the toggle. When the toggle is on, it also hashes the title, description, the first 1000 characters of content, and the summary ([`buildWebPageHashComponents`, `translate-text.ts#L102-L176`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/translate-text.ts#L102-L176)). Entries also expire after 7 days ([`db-cleanup.ts#L9`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/background/db-cleanup.ts#L9)). The streamed LLM path for selection translation calls `streamBackgroundText` directly and skips this cache ([`provider.tsx#L190-L204`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/translate-button/provider.tsx#L190-L204)). Only its summary is cached.

## 3. Word/phrase vs. sentence, and source-language detection

### 3.1 Word/phrase vs. sentence

- **Current Read Frog has no automatic classifier.** The user chooses by clicking Translate or a custom action such as Dictionary in the selection toolbar. The Dictionary prompt assumes its input is a term.
- The only prompt that classifies is the legacy `getWordExplainPrompt`, where the LLM decides as step 1 of the prompt and picks a template (section 1.6). It has no caller.
- Local word-count heuristics exist, but for unrelated purposes:
  - `Intl.Segmenter` word counting skips tiny paragraphs during page translation ([`filter-small-paragraph.ts#L9-L38`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/filter-small-paragraph.ts#L9-L38)).
  - A rule of at most 24 characters and 4 whitespace-separated words decides inline rendering of short page translations ([`translation-utils.ts#L10-L34`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/ui/translation-utils.ts#L10-L34)).

### 3.2 Source-language detection

[`detectLanguageWithSource`, `content/language.ts#L51-L98`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/content/language.ts#L51-L98) works in three steps:

1. Text shorter than `minLength` (default 10) returns `und`.
2. If `enableLLM` is set, it tries the LLM prompt (section 1.4) on the text, truncated to 500 characters. The prompt is attempted up to 3 times ([`#L120-L209`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/content/language.ts#L120-L209)). On failure it warns the user with a toast.
3. Otherwise, or as the fallback, it uses **`franc`** (`franc@^6.2.0`), validated against the supported ISO 639-3 list.

`languageDetection.mode` is `basic` (franc) or `llm`. The default is `basic` ([`constants/config.ts#L128-L130`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/config.ts#L128-L130)).

Where each mode applies:

| Caller | Method |
|---|---|
| Page language ([`page-language.ts#L183-L219`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/content/page-language.ts#L183-L219)) | `<html lang>` or meta locale first. Otherwise franc on the title plus a DOM text sample. LLM is always off. |
| Per-paragraph skip check ([`translate-text.ts#L62-L76`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/translate-text.ts#L62-L76)) | franc only, by design (cost) |
| Translation Hub input ([`language-control-panel.tsx#L28-L40`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/translation-hub/components/language-control-panel.tsx#L28-L40)) | franc, or LLM if mode is `llm`. `minLength: 1`, debounced 1 s. |
| TTS voice choice ([`use-text-to-speech.tsx#L59-L84`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/hooks/use-text-to-speech.tsx#L59-L84)) | franc, or LLM if mode is `llm` |

The detected source language does not enter the translation prompt, which has no source token. It feeds UI, skip rules, TTS, and non-LLM translation APIs (as `sourceLang`). It also fed the legacy word-explain prompt. The default `language.sourceCode` is `auto` and the default target is `cmn` ([`constants/config.ts#L82-L86`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/constants/config.ts#L82-L86)).

## 4. sidelingo steps with no Read Frog counterpart

- **Structuring into Markdown (text).** No Read Frog prompt turns raw text into structured, readable Markdown. The nearest pieces are these:
  - Defuddle converts page HTML to Markdown locally, for summary context only, with no LLM involved (section 2).
  - The translation prompts preserve the input's paragraph and list structure; they do not create it.
  - The subtitle segmentation prompt restructures word fragments into sentence cues, but only for timed subtitles.
- **Structuring images, and any vision prompt.** None exist. Every prompt payload is a text `instructions` plus a text `prompt` string ([`background-generate-text.ts`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/types/background-generate-text.ts#L4-L15)). A search of `src/` for image message parts, `image_url`, OCR, or screenshot capture finds none. The only "vision" matches are model ids in model lists and migrations.
- **Automatic Entry vs. running-text routing.** Absent today (section 3.1). The legacy word-explain prompt is the only prior art.
- **Lookup with independent source-language and target-language explanations.** The current Dictionary gives one target-language Definition plus a sentence and its translation. The legacy word-explain word template is the only prompt that asks for a definition in both the source and the target language. It does so inside a single output, not as two independent calls.

## 5. Browser-only inputs that a clipboard-driven desktop app would need to replace

| Input | Read Frog source | Used by | Behaviour when absent |
|---|---|---|---|
| `webTitle` | `document.title` | Translation system prompt (built-ins), summary prompt, Dictionary/custom-action token, note suggestion | Translation gets `"No title available"`. The summary is skipped because both title and content must be non-empty ([`webpage-summary.ts#L21-L24`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/utils/host/translate/webpage-summary.ts#L21-L24)). |
| `webSummary` | LLM summary of `webContent` | Translation system prompt (built-ins) | `"No summary available"` |
| `webContent` | Defuddle Markdown of the DOM, 2000 characters | Summary input; custom translation prompts; custom-action token | `"No content available"` (translation) or `""` (custom action) |
| `webDescription` | `<meta>` description tags | Custom translation prompts only | `"No description available"` |
| `webUrl` | `window.location.href` | Custom-action token only (the Dictionary does not use it) | n/a |
| `selection` | Window selection text | Dictionary and custom actions | The action refuses to run (`missingSelection`) |
| `paragraphs` | DOM block elements that intersect the selection, joined with blank lines and truncated to 2000 characters ([`selection.content/utils.ts#L398-L423`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/utils.ts#L398-L423)) | Dictionary (sense disambiguation, sentence extraction) | Falls back to the selection itself ([`use-custom-action-execution.ts#L176-L183`](https://github.com/mengxi-ream/read-frog/blob/b4a45b9455eb0f63b450cb9610d87ac33883f0e9/src/entrypoints/selection.content/selection-toolbar/custom-action-button/use-custom-action-execution.ts#L176-L183)) |
| Page language metadata | `<html lang>`, meta locale | Page-level detection | franc on the text |
| Video title and transcript | Player DOM and caption fetchers | Subtitle prompts (out of scope) | n/a |

The Translation Hub is the Read Frog surface closest to a clipboard app. It translates typed text with no page context, so every web token takes its fallback value, and the language detection above still applies.

# Packaged license omissions

The notices generator normally reads full license and notice files from the installed npm packages. These packages omit their license files, so it uses the following upstream texts, only for the exact package versions listed in the generator. New versions require checking the omission and upstream terms again.

- `@fluentui/react-icons` 2.0.343: [Microsoft Fluent System Icons LICENSE](https://github.com/microsoft/fluentui-system-icons/blob/a563cf9166f4f91aa617557ed272612b7f0a2f72/LICENSE), stored in `fluentui-system-icons.txt`.
- `embla-carousel`, `embla-carousel-autoplay` and `embla-carousel-fade` 8.6.0: [Embla Carousel v8.6.0 LICENSE](https://github.com/davidjerleke/embla-carousel/blob/0fe65834136f1aa35e4c1a4a477e5ccb4bb5ee54/LICENSE), stored in `embla-carousel.txt`.
